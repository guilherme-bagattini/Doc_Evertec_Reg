
# Doc_Evertec_Reg

Repositorio de apoio para centralizar contexto, requisitos e materiais de consulta do projeto EvertecReg.

## Objetivo

Organizar a base de conhecimento do projeto para facilitar:

- entendimento rapido do dominio;
- preparacao para reunioes;
- acompanhamento de decisoes do MVP;
- registro de duvidas e pendencias;
- consulta de referencias funcionais e tecnicas;
- consulta de pesquisa com clientes (entrevistas, retencao, churn).
